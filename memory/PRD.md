# PRD — IELTS Center Platform (MVP v2)

## 1) Оригинальный запрос пользователя
Построить серьёзный минималистичный и современный IELTS-сайт с публичной страницей (hero, о нас, программа, успехи, отзывы, заявка, футер), мультиязычностью RU/EN/KK, входом, админ-панелью и мультифилиалами. В админке: менять название/лого/цвета/тексты сайта, обрабатывать заявки, вести учеников/преподавателей/классы, управлять группами, переводить между группами, вести индивидуальные занятия как отдельные группы, настраивать и создавать расписание с автослотами и проверкой конфликтов, а студентам показывать личное расписание после входа.

## 2) Архитектурные решения
- **Стек**: FastAPI + MongoDB (Motor) + React (Vite) + React Router + Axios + Sonner + Lucide + React-Leaflet.
- **Мультифилиалы**: master DB хранит `branches` и `users`; каждый филиал получает **свою отдельную MongoDB** (`db_name`) для изоляции данных.
- **RBAC**: роли `superadmin` и `student` (поддержка `admin` в API).
- **Настройки сайта из админки**: `site_settings` в БД филиала; публичный сайт читает тексты/цвета/лого/контакты/отзывы/точки карты из API.
- **Расписание**: отдельные сущности `teachers`, `classrooms`, `groups`, `schedules`, `schedule_settings`; конфликты преподавателей/классов проверяются на API.

## 3) Что реализовано
- Публичный лендинг IELTS Center с секциями, соцссылками, телефоном, переключением языка RU/EN/KK.
- Добавлен пункт меню и отдельная секция **«Наши преподаватели»** с карточками преподавателей.
- Убран публичный selector филиалов из hero; главная стала единой по структуре.
- Форма заявки расширена: ФИО + выбор филиала («Какой филиал вам ближе?») + телефон.
- Добавлена интерактивная карта филиалов с точками и адресами на главной странице.
- Логин-система (JWT), superadmin + студент-вход; убран выбор филиала на странице входа.
- Админ-панель:
  - Вкладка **Филиалы**: создание, редактирование и удаление филиала (с удалением БД филиала).
  - Создание филиала (новая БД) + переключение филиала.
  - Редактор сайта: название, лого, телефон, соцсети, цвета, тексты RU/EN/KK.
  - Редактирование отзывов соцсетей (добавление/изменение/удаление).
  - Редактирование точек филиалов на карте (название, адрес, lat/lng).
  - Лиды: просмотр и подтверждение в учеников (автогенерация/задание логина-пароля).
  - Лиды: добавлено **отклонение заявки** и **поиск по имени/телефону** + фильтр по статусу.
  - Лиды: массовые действия — удаление **выбранных** и **очистка всех** заявок.
  - Ученики: смена логина/пароля.
  - CRUD преподавателей и классов.
  - Расширенный профиль преподавателя: фото, специализация, биография RU/EN/KK.
  - Группы: создание/удаление, привязка ученика, перевод между группами.
  - Группы: правило ограничений — максимум **1 общая + 1 индивидуальная** группа на ученика.
  - Группы: выпуск группы в раздел **Выпускники** с удалением student-аккаунтов и удалением из активных.
  - Группы: обзор всех учеников и их текущих групп во вкладке групп.
  - Выпускники: отдельная вкладка, поиск, удаление выбранных и очистка всех.
  - Расписание: настройки рабочего дня, автослоты, ручное создание, проверка конфликтов, удаление записей.
  - Расписание: добавлено **редактирование существующих занятий**, применение авто-слота в форму, live-статусы занятости преподавателя/класса (красный/зелёный).
  - Расписание: автослоты и проверка конфликтов работают автоматически при изменении параметров (без ручной проверки).
  - Аккаунт: смена логина/пароля администратора из админки.
- Кабинет студента: страница расписания по дням недели после входа.
- Исправлен критический баг transfer (Mongo conflict при `$pull` + `$addToSet` в одном update).
